Task 1 - Startup Pitch Registration Page

A registration page for the E-Cell Startup Pitch Competition, built with plain HTML, CSS, and JavaScript.

Features
Registration form with fields: full name, email, phone number, team name, and startup idea
Frontend validation for every field (empty name, invalid email, phone must be exactly 10 digits, idea description too short, etc.)
Success message shown after valid submission
A searchable list of existing UIET startups (search box filters cards live as you type)
Files
Ecell_1.html - page structure
style.css - styling
script.js - form validation and search logic
How to run
Download all three files (Ecell_1.html, style.css, script.js) into the same folder.
Open Ecell_1.html in any browser (double-click it, or right-click -> Open with -> your browser).
No installation or server needed, it's a static page.
Tech used

HTML, CSS, vanilla JavaScript .
